The entry is one sentence about a grandmother whose durability has become a
problem for the local poultry. It is 74 characters, delivered by a small
standard-library Python script that copies the text from `LINE.txt` into
`/output/entry.txt`. The drafting record lives in `CANDIDATES.md`: sixteen
attempts, the three that survived, and a note on which ones were only clever.

## The line

> My grandmother has outlived three husbands and one very confident rooster.

The first four words read like an obituary; the last three are the swerve. The
rooster carries the whole joke without the sentence ever explaining it.

## Run it

    python3 main.py        # writes /output/entry.txt
    cat /output/entry.txt
